# Swing Menü Kontrolleri

Java Swing ile menü ve pencere bileşenlerini tanıtan örnekler (Java kursu).
Her sınıfın kendi `main` metodu vardır; tek başına çalıştırılabilir.

Paket: `com.zeynepbaydogan.swing`

| Sınıf | Gösterdiği bileşen |
|---|---|
| `FrameOrnek` | `JFrame` — temel pencere |
| `MenuBarOrnek` | `JMenuBar` — pencerenin üstündeki menü çubuğu |
| `MenuOrnek` | `JMenu` — menü çubuğundaki menüler |
| `MenuItemOrnek` | `JMenuItem` — tıklanabilir menü öğeleri |
| `SeperatorOrnek` | `JSeparator` — menü öğeleri arasına ayırıcı çizgi |
| `CheckBoxMenuOrnek` | `JCheckBoxMenuItem` — işaretlenebilir menü öğesi |
| `RadioMenuOrnek` | `JRadioButtonMenuItem` — gruptan tek seçim yapılan menü öğesi |
| `PopupMenuOrnek` | `JPopupMenu` — sağ tıklayınca açılan menü |
| `DialogOrnek` | `JDialog` — açılır diyalog penceresi |
| `FileChooserOrnek` | `JFileChooser` — dosya seçme penceresi |
| `ColorChooserOrnek` | `JColorChooser` — renk seçme penceresi |

## Çalıştırma

1. Eclipse: **File → Import → General → Existing Projects into Workspace** ile bu klasörü seç.
2. Proje Java 25 ile ayarlıdır ve modül kullanır (`module-info.java` → `requires java.desktop`).
3. İstediğin sınıfa sağ tıkla → **Run As → Java Application**.
